About

what I actually do

I work on the layer most people never see: the handshake between a browser, an application and a directory that happens before anyone reaches a dashboard.

Most of that work is interop. An assertion a service provider quietly refuses. A WS-Trust token issued for the wrong audience. A RADIUS request that times out only under load. An LDAP filter that returns nothing at 2am and everything at 9. I like tracing those as much as I like building the thing that gets traced.

Underneath it all is ordinary engineering — Java, C, C++ and Python — plus the operational side of keeping identity available: load balancing, domain controllers, and enough Elasticsearch to find the one request that failed.
